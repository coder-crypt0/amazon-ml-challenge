# Dataset profile

Generated by streaming the six source TSVs and the training ground truth. No external data was used; source IDs were checked only for uniqueness.

## Source sizes and coverage

| split/source | rows | countries | missing address |
|---|---:|---|---:|
| train/source1 | 2,206,821 | US 1,323,633; India 883,188 | 0 |
| train/source2 | 5,034,616 | India 2,017,799; US 3,016,817 | 168,967 (3.36%) |
| train/source3 | 5,285,603 | US 3,170,056; India 2,115,547 | 175,916 (3.33%) |
| test/source1 | 1,732,544 | US 663,106; France 259,452; India 809,986 | 0 |

| test/source3 | 5,082,316 | India 2,405,000; France 731,615; US 1,945,701 | 136,098 (2.68%) |

All source entity IDs are unique within their file. Business names and countries are complete in the scanned files; missingness is concentrated in source2/source3 addresses. France appears in test only, so country should be treated as a strong blocking/normalization signal and train-only country assumptions should be avoided.

## Ground truth structure

- 2,206,821 source1 rows; every source1 ID is unique in ground truth.
- 123,247 rows (5.59%) have zero matches.
- Match cardinality: 1: 119,157; 2: 375,212; 3: 530,841; 4: 484,115; 5: 321,957; 6: 164,868; 7: 63,968; 8: 18,680; 9: 4,205; 10: 534; 11: 37.
- 7,638,365 distinct matched target IDs occur across the truth file; no row contains duplicate target IDs.
